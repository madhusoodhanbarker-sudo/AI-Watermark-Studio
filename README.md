# 💧 AI Watermark Studio

AI Watermark Studio is a Streamlit-based application that allows users to add **Text** and **Logo Watermarks** to Images, Videos, PDF Documents, and Microsoft Word Documents.

---

## 🚀 Features

### 🖼️ Image Watermark
- Upload PNG, JPG, JPEG, WEBP
- Add Text Watermark
- Add Logo Watermark
- Opacity Control
- Font Size
- Font Color
- Rotation
- Multiple Positions
- Transparent Watermark
- Download Processed Image

---

### 🎥 Video Watermark
- Upload MP4, AVI, MOV, MKV, WEBM
- Text Watermark
- Logo Watermark
- Adjustable Opacity
- Watermark Position
- Watermark Scaling
- Live Preview
- Download Processed Video

---

### 📄 PDF Watermark
- Text Watermark
- Logo Watermark
- Apply to Every Page
- Transparent Watermark
- Diagonal Watermark
- Download Watermarked PDF

---

### 📄 Word Document Watermark
- Text Watermark
- Header Watermark
- Company Logo
- Confidential Stamp
- Save as DOCX

---

## ⭐ Advanced Features

- Batch Processing
- Drag & Drop Upload
- Watermark Rotation
- Watermark Scaling
- Logo Upload
- Download Processed Files
- Responsive Streamlit UI

# 📦 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/AI-Watermark-Studio.git
```

Go to the project folder

```bash
cd AI-Watermark-Studio
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```

# 🌐 Deployment

Deploy the application on **Streamlit Community Cloud**.

2. Open Streamlit Community Cloud.
3. Connect your GitHub repository.
4. Select **app.py**.
5. Click **Deploy**.
